# Apply Visual Direction

Follow [Brix](../../AGENT.md). Consume the canonical selection, screen coverage, requirements and shared inspection evidence. Do not re-analyze reference candidates or re-open valid unchanged evidence. Uncovered new screens return to the single research task; continue independent ready screens.

## Compose

For each ready screen, map selected relationships to actual content: dominant masses, proportions, focal order, alignment, whitespace, density and image/text balance. Refer to selection IDs rather than repeating their analysis or choice reasons. Add only new application decisions: target regions, what is preserved/adapted, and why content or identity needs that adaptation. Qualitative observations are not measured CSS values.

Use the same semantic tokens, typography and reusable control families across all references. A new source's button style does not redefine product identity. Preserve useful composition without replacing it with a generic stack; adapt it to actual content and the existing controls. Send genuinely missing component behaviors to the identity manager. If composition cannot fit required content, revise the application or return only its reference gap; do not remove required functionality.

Consume confirmed locale and form-state decisions. Check current scoped rejections and resolve pinned evidence. Do not reinterpret a rejected source via aliases/crops or rewrite intended rules to excuse a visibly failed output.

## Identity dependencies

Existing projects use their authoritative identity. New projects may produce a draft with labeled proposed treatments before identity exists. Send only the required proposal decisions to the identity manager; finalize using the adopted identity and existing shared preview evidence. Identity records own values; direction links them. Do not create another token catalog or impose a whole-library task.

Identify required production assets by use, proportions and content clearance; references are not automatically licensed product assets. Route those needs to the asset manager.

## Output

Use the existing task/direction record for new application decisions, selected IDs, affected screen/part IDs, identity revision, required sizes/states and inspection targets. It may be a task section; a separate report is not mandatory. Return its location/revision. `draft` supports authorized previews; `ready` supports only covered scope with usable adopted identity. This skill does not write Figma or grant external publishing permission.
